# Pokedex
Esta é uma Pokédex interativa desenvolvida consumindo uma API pública de Pokémon.
O projeto permite buscar e visualizar informações de diferentes Pokémon, exibindo nome e imagem diretamente na interface inspirada em uma Pokédex.

HTML5 → Estrutura da aplicação
CSS3 → Estilização e posicionamento dos elementos
JavaScript (ES6+) → Lógica da aplicação e consumo da API
PokéAPI → API pública utilizada para obter os dados dos Pokémon
